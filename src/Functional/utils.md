# Утилиты

Здесь описаны функции, которые облегчат вашу работу с функциями.

---

## pipe
Позволяет делать композицию нескольких функций.
Первым аргументом принимает список из функций.Принимает вторым аргументом аргумент, который подастся первую функцию.
Аргумент сначала подается в первую функцию, потом результат первой во вторую и.т.д.
`func (arg funcs) pipe`
```
(pipe (list (+ 5) (- 6)) 1) // вернет 0
```
## pipe-monadic
Позволяет производить монадические вычисления. Принимает первым аргументом bind, вторым список функций, который принимают немонадический тип, а возвращают монадический, третьим аргумент. 
`func pipe-monadic (bind funcs arg)`
Примеры смотрите в [Монады](./monads.md)
