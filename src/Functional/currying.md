# Каррирование

Язык Cheremsha поддерживает удобную запись каррирования

---
Недописав все аргументы функции, вы можете создать функцию, в которой заранее будут применены аргументы.
> [!IMPORTANT]
> Каррирование не работает для функций с неопределенным количество аргументов. Например `list`, `and`, `or`
## Примеры
Функция, которая прибавляет 5:
```
(+ 5)
```
Функция, которая проверяет является ли переменная int.
```
(is-type int)
```
