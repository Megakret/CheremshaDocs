# Quickstart
## Что за язык 
Cheremsha или Черемша - функциональный язык программирования, вдохновленный [Lisp](https://ru.wikipedia.org/wiki/%D0%9B%D0%B8%D1%81%D0%BF).

- Функции

## Цель
На основе написания факториала мы покажем вам, как писать на нашем языке.
## Запуск программы
Вы можете использовать интерпретатор двумя способами:
1. Как REPL. Вызовете интерпретатор без аргументов.
`dotnet run`
2. Исполнить скрипт. В аргумент передайте имя файла.
`dotnet run -- sample.x`
## Выражение 
Вся программа представляет из себя набор выражений. Выражение может быть **атомом** и **списком** из атомов.
```
// Примеры атомов
1           // Int
1.2         // Float
"Cheremsha" // String
x           // Имя переменной или функции
true        // Bool
false       // Bool
// Пример списка
(+ 1 2) //Вызов функции, о нем дальше
```
> [!NOTE]
> Комментарии начинаются с //
## Вызов функции
В списке везде, кроме особых форм(о них дальше) первый элемент является функцией,
а следующие - ее аргументами. Сначала подсчитываются аргументы,
а потом сама функция.
```
(+ 1 2)       //3
(< 1 3)       //true
(* (+ 1 2) 3) // 9
```
Отлично теперь вы умеете вызывать функции, но как определить сами функции.
## Создание функций
Чтобы создать функцию используется **особая форма** **func**. Особые формы отличаются от функций тем, что их аргументы интерпретируются по другому. Вот например функция умножения.
```
(
    func multiply (x y) (
        (* x y)
    )
)
```
func принимает имя функции, список из названий аргументов
и тело функции в виде **списка из выражений**.
> [!IMPORTANT]
> Обратите внимание на формулировку список из выражений. Код 
> `(func multiply (x y) (* x y))`
> не будет работать, но код `(func one (x) (1))` будет.

Результат последнего выражения является результатом функции (позже объясню почему так сделано).
Все функции, созданные через func, рекурсивны по умолчанию.
## Условия
Для факториала необходимо написать условие выхода из рекурсии.
Условный оператор реализован, как особая форма **if**.
Она первым аргументом принимает условие, вторым список выражений(как в func).
```
(
    if (= n 0)
    (
        // true branch
        1
    )
    (
        // false branch
        2        
    )
)
```
## Сам факториал
Теперь мы готовы написать функцию факториала. Она выглядит так:
```
(
    func factorial (n) ( // n - аргумент функции
        (
            if (= n 1)   // условие выхода
            (1)          // true branch
            (            // false branch
                (* (factorial (- n 1)) n) // аналог factorial(n - 1) * n на нашем языке
            )
        )
    )
)
```
## Переменные
Теперь когда вы умеете писать функции, можете результат этой функции присвоить переменной. Переменные создаются с помощью особой формы **let**. Она первым аргументом принимает список из декларация. Декларация: `(имя значение)`.
```
(let
(
    (x (factorial 5))
    (y 1)
    (s "hello world")
)
)
```
### Как использовать let в func и if
Вы можете использовать let в функциях и условиях следующим образом:
```
// Гамма функция для натурального числа (Г(n+1) = n!)
(func gamma-for-n (n) (
    (
        let 
        ((x (- n 1))) // Первое выражение добавляет переменную x
    )
    (factorial x) // Второе возвращает результат функции
)
)
```
В if аналогично.
