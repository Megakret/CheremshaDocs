# Разделение на файлы

Cheremsha поддерживает разбиение программы на несколько файлов с помощью `include`.

## include
Выполняет код из файла `filename` и загружает все определённые в нём имена в текущее окружение.

`(include "filename")`

`filename` — строковый литерал с путём к файлу. Путь указывается относительно рабочей директории интерпретатора.

Выражения в файле выполняются последовательно в том же окружении, в котором вызван `include`. Имена, определённые через `func` и `let` в файле, становятся доступны после возврата из `include`.

> [!NOTE]
> Многострочный код поддерживается только в файлах. В REPL каждая строка обрабатывается отдельно — используй `include` для загрузки многострочных определений.

Файл `math.x`:
```
(func square (x) ((* x x)))
(func cube (x) ((* x (* x x))))
```

Основной файл:
```
(include "math.x")

(square 4)  // 16
(cube 3)    // 27
```

Вложенный `include` — файл может подключать другие файлы:
```
// geometry.x
(include "math.x")

(func circle-area (r) ((* 3.14159 (square r))))
```

```
(include "geometry.x")

(circle-area 5)  // 78.53975
```
