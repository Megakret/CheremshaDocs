# Модули

Модуль группирует связанные функции и переменные под общим именем, предотвращая конфликты имён.

## module
Выполняет тело модуля в изолированном окружении и добавляет все определённые имена с префиксом `Name.` в текущее окружение.

```
(module Name (
    expr1
    expr2
    ...
))
```

`Name` — идентификатор модуля. Тело — последовательность выражений, обычно `func` и `let`.

После выполнения `(module Math (...))` имена, определённые внутри, становятся доступны как `Math.foo`, `Math.bar`. Неквалифицированные имена снаружи модуля недоступны.

> [!NOTE]
> Многострочный синтаксис модуля поддерживается только в файлах. В REPL вся конструкция должна быть на одной строке: `(module Name ((func foo (x) (x))))`.

```
(module Math (
    (func square (x) ((* x x)))
    (func cube (x) ((* x (* x x))))
    (let ((pi 3.14159)))
))

(Math.square 5)  // 25
(Math.cube 3)    // 27
Math.pi          // 3.14159

(square 5)       // ошибка: Symbol square not found
```

### Несколько блоков одного модуля
Один модуль можно определять в нескольких блоках — имена из всех блоков добавляются в общее пространство имён.

```
(module Strings (
    (func to-upper (s) (...))
))

(module Strings (
    (func to-lower (s) (...))
))

(Strings.to-upper "hello")  // работает
(Strings.to-lower "HELLO")  // работает
```

### Рекурсия
Функции внутри модуля вызывают себя по неквалифицированному имени:

```
(module Math (
    (func fact (n) (
        (if (= n 0)
            1
            ((* n (fact (- n 1))))
        )
    ))
))

(Math.fact 5)  // 120
```

### Замечания
Модули не создают отдельного пространства имён в памяти — это соглашение по именованию, применяемое автоматически интерпретатором. Функции внутри модуля видят друг друга по неквалифицированным именам, но снаружи доступны только через `Name.`.
