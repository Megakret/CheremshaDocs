# Переменные
## let
Вы можете создать переменную с помощью let.
Как в любом функциональном языке, вы не можете модифицировать
переменные.
```
(let
    (N 5)
    (x (+ N 1))
)
```
let принимает список из деклараций.

Декларация: список из имени переменной и значения.

> [!NOTE]
> Вы можете в let ссылаться на другие переменные, объявленные в том же let. В примере x использует N.

Каждая переменная живет в своем лексическом окружении. Глобальном или окружении функции.
Когда вы вызываете **func** или **la** для создания функции, все что лежит внутри функции лежит в своем окружении.
```
(let ((t 1))) //Какая-то константа
(func second (l) //Находит второй элемент списка
(
    (let
        (
            (t (tail l)) // Все кроме первого элемента списка
            (ans (head t))
        )
    )
    ans
)
)
```
