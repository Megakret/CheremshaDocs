## Int
Целое число. С ним доступны операции:
- `(+ 1 2)`
- `(- 1 2)`
- `(* 1 2)`
- `(/ 1 2)` - с округлением вниз
- `(- 1)` - унарный минус
- `(= 5 5)`
- `(< 3 5)` -> `true`
- `(> 3 5)` -> `false`
- `(<= 3 5)`
- `(>= 3 5)`
> [!NOTE]
> В этих операциях может участвовать только либо 2 int, либо 2 float.
Вы можете преобразовывать float в int. Преобразование отсекает дробную часть:
`(int val)`
## float
Доступны все те же операции, что и для int.

Вы можете преобразовывать int в float. `(float val)`.

Вы можете округлить float по правилам математики `(round val)`.
## bool
Логический тип данных. Записывается атомами:
- `true` - истина;
- `false` - ложь.

Во всех контекстах, где ожидается значение типа `bool`, небулевы значения неявно преобразуются по правилу:
- `nil` преобразуется в `false`;
- всё остальное преобразуется в `true`.

Язык предоставляет стандартный набор логических операций:
- `(not val)` - возвращает значение обратное переданному  
  (e.g., `(not true)` -> `false`, `(not false)` -> `true`);
- `(and a b c ...)` - последовательно вычисляет выражения до первого ложного либо до конца списка, возвращая `true`, если все значения истины, либо `false`, если хотя бы одно из них ложно  
  (e.g., `(and true true)` -> `true`, `(and true false true)` -> `false`);
- `(or a b c ...)` - последовательно вычисляет выражения до первого истинного либо до конца списка, возвращая `true`, если хотя бы одно значение истино, либо `false`, если все они ложны  
  (e.g., `(or false true)` -> `true`, `(or false false false)` -> `false`).

Поддерживает операцию проверки равенства:
- `(= true true)` -> `true`;
- `(= false true)` -> `false`;
- `(= false false)` -> `false`.
> [!NOTE]
> Во всех контекстах, где ожидается значение типа `bool`, небулевы значения неявно преобразуются по правилу:
> - `nil` преобразуется в `false`;
> - всё остальное преобразуется в `true`. 
## string
Строковой тип данных.

Доступна операция конкатенации: `(+ "Hello, " "world!")` -> `"Hello, world!"`.

Поддерживает операции лексиграфического сравнения:
- `(= "hello", "hello")` -> `true`;
- `(< "a", "b")` -> `true`;
- `(> "a", "b")` -> `false`;
- `(<= "a", "b")` -> `true`;
- `(>= "a", "b")` -> `false`.
