# Функции

Вы можете создать 2 типа функций. Анонимные (лямбда выражения) и именованные.

---
## Именованные функции
Создать именованную функцию можно с помощью особой формы **func**. Синтаксис выглядит как

`(func имя-функции (список из имен аргументов) (список из выражений))`.

 Список из выражений в функции интерпретируется до тех пор, пока какое-то выражение не вернет результат. Например **let** результат не возвращает.
 Это сделано для того, чтобы вы могли именовать переменные в функции.
 Пример:
 ```
(
    func double-list (l) // Умножает все элементы списка на 2
    (
        ( if l
            (
                (let
                (
                    (x (* 2 (head l)))
                    (new-head (list x))
                    (new-tail (tail l))
                )
                )
                (cat new-head (double-list new-tail))
            )
            nil
        )
    )
)
 ```
В примере вы так же можете видеть, что именованные функции по умолчанию поддерживают рекурсию
## Лямбда выражения
Создаются с помощью особой формы **la**. Синтаксис выглядит как

`(la (аргументы) (список из выражений))`

Список из выражений интерпретируется так же, как и в **func**.
> [!IMPORTANT]
> Лямбда выражение не поддерживает рекурсию, даже, если вы дадите ему имя с помощью let

## Функция как аргумент
Вы можете использовать функцию, как аргумент к другим функциям. Для определения таких функций
удобно написать лямбда выражение.
Пример использования типичной функции map для списков.
```
(
    func ListMap (f lst)
    (
        (if lst
        (
            (let
            (
                (x (f (head lst)))
                (new-head (list x))
                (new-tail (tail lst))
            )
            )
            (cat new-head (ListMap f new-tail))
        )
        (
            lst
        )
        )
    )
)
(ListMap (la (x) ((* x x))) (list 1 2 3)) // Квадрат от всех элементво списка
// [1, 4, 9]
```
## Функция, как возвращаемое значение
Ваша функция может вернуть другую функцию.
Пример:
```
(func make-adder (x)
(
    (
        la (y) (
        (+ x y)
        )
    )
)
)
(
    let
    ((add5 (make-adder 5))) //Функция, которая прибавляет 5
)
(add5 1) // 6
```
> [!TIP]
> Предыдущий пример можно было написать и короче. Наш язык поддерживает 
> каррирование. Получить функцию `(make-adder 5)` можно было записью `(+ 5)`
