## map
Ассоциативная коллекция, хранящая пары "ключ-значение". Ключами могут являться только `int`, `float` и `string`. Все ключи в одном `map` могут иметь только один тип. Одному ключу может принадлежать только одно значение.

Операции с `map`:
- `(map (("apples" 2) ("bananas" 2) ("oranges" 8)))` - создание `map` из переданного списка пар;
> [!NOTE]
> Если в списке пар окажется несколько пар с одинаковым ключом, сохраняется значение из самой правой такой пары.
- `(map-get m key)` - получение значения, связанного с ключом `key` из `m`;
> [!NOTE]
> Если переданный ключ отсутствует в `map`, возвращает значение `nil`.
- `(map-insert m key value)` - возвращает новый `map`, в котором `key` связан со значением `value`;
- `(map-delete m key)` - возвращает новый `map`, в котором нет пары с ключом `key`.
> [!NOTE]
> Если переданный ключ отсутствует в `map`, ошибка не возникает - возвращает копию переданного `map`.

> [!NOTE]
> `nil` нельзя хранить в `map` в качестве значения.
