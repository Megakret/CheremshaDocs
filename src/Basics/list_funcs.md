# Библиотечные функции для List 

В данном разделе описаны основные инструменты для работы со списками. Функции `fst` и `snd` являются глобальными, в то время как остальные сгруппированы в модуле `List`.

## Глобальные функции

### fst
Возвращает первый элемент списка. Является алиасом для встроенной функции `head`.

`(fst list)`

```lisp
(fst (list 1 2 3)) // 1
(fst nil)          // ошибка: head: empty list
```

### snd
Возвращает второй элемент списка. Эквивалентно получению головы от хвоста списка.

`(snd list)`

```lisp
(snd (list "первый" "второй" "третий")) // "второй"
(snd (list 1))                         // ошибка: tail: empty list
```

## Модуль List

Для использования функций этого модуля необходимо использовать префикс `List.`

### Map
Применяет функцию `f` к каждому элементу списка `lst` и возвращает новый список результатов[cite: 2].

`(List.Map f lst)`

```lisp
(func square (x) ((* x x)))
(List.Map square (list 1 2 3)) // List [1, 4, 9]
```

### Filter
Создает новый список, содержащий только те элементы `lst`, для которых предикат `pred` вернул `true`. Если предикат возвращает `nil` или `false`, элемент отбрасывается.

`(List.Filter pred lst)`

```lisp
(List.Filter (la (x) ((> x 0))) (list -1 5 -2 8)) // List [5, 8]
```

### Fold
Сворачивает список `lst`, последовательно применяя функцию `f` к аккумулятору `acc` и очередному элементу.

`(List.Fold f acc lst)`

```lisp
// Сумма элементов:
(List.Fold + 0 (list 1 2 3)) // 6
```

### Nth
Возвращает элемент по указанному индексу `n` (индексация начинается с 0). Если индекс выходит за пределы списка, возвращает `nil`.

`(List.Nth n lst)`

```lisp
(List.Nth 1 (list "a" "b" "c")) // "b"
(List.Nth 5 (list 1 2))         // nil
```

### Length
Вычисляет количество элементов в списке. Работает рекурсивно.

`(List.Length lst)`

```lisp
(List.Length (list 1 2 3 4)) // 4
(List.Length nil)            // 0
```

### Rev
Переворачивает список, меняя порядок элементов на обратный. Использует `Fold` для построения нового списка. Сложность операции — $O(n)$.

`(List.Rev lst)`

```lisp
(List.Rev (list 1 2 3)) // List [3, 2, 1]
```

### Fold2
Аналог `Fold`, но обрабатывает два списка одновременно. Итерация прекращается, как только один из списков заканчивается.

`(List.Fold2 f acc l1 l2)`

```lisp
// Создание списка пар:
(List.Fold2 (la (acc x y) ((cat acc (list (list x y))))) nil (list 1 2) (list 3 4))
// List [[1, 3], [2, 4]]
```

### Push
Добавляет элемент `x` в начало списка `lst`. Фактически является оберткой над `cat` и `list`.

`(List.Push x lst)`

```lisp
(List.Push 10 (list 1 2)) // List [10, 1, 2]
```

### Pop
Возвращает список без первого элемента. Эквивалентно встроенной функции `tail`.

`(List.Pop lst)`

```lisp
(List.Pop (list 1 2 3)) // List [2, 3]
```
