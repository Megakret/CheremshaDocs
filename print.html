Cheremsha documentation

Quickstart

Что за язык

Cheremsha или Черемша - функциональный язык программирования, вдохновленный Lisp.

Основные фичи

  • Именованные переменные (let)
  • Функции
  • Рекурсия
  • Замыкание
  • Ввод-вывод файлов и в консоль
  • Списки
  • Мапа
  • Каррирование
  • Stack trace(для удобного вывода ошибок)
  • Модули и инклюды
  • Библиотечные функции для map

Цель

На основе написания факториала мы покажем вам, как писать на нашем языке.

Запуск программы

Вы можете использовать интерпретатор двумя способами:

  1. Как REPL. Вызовете интерпретатор без аргументов. dotnet run
  2. Исполнить скрипт. В аргумент передайте имя файла. dotnet run -- sample.x

Выражение

Вся программа представляет из себя набор выражений. Выражение может быть атомом и списком из атомов.

// Примеры атомов
1           // Int
1.2         // Float
"Cheremsha" // String
x           // Имя переменной или функции
true        // Bool
false       // Bool
// Пример списка
(+ 1 2) //Вызов функции, о нем дальше

Note

Комментарии начинаются с //

Вызов функции

В списке везде, кроме особых форм(о них дальше) первый элемент является функцией, а следующие - ее аргументами. Сначала подсчитываются аргументы, а потом сама функция.

(+ 1 2)       //3
(< 1 3)       //true
(* (+ 1 2) 3) // 9

Отлично теперь вы умеете вызывать функции, но как определить сами функции.

Создание функций

Чтобы создать функцию используется особая форма func. Особые формы отличаются от функций тем, что их аргументы интерпретируются по другому. Вот например функция умножения.

(
    func multiply (x y) (
        (* x y)
    )
)

func принимает имя функции, список из названий аргументов и тело функции в виде списка из выражений.

Important

Обратите внимание на формулировку список из выражений. Код (func multiply (x y) (* x y)) не будет работать, но код (func one (x) (1)) будет.

Результат последнего выражения является результатом функции (позже объясню почему так сделано). Все функции, созданные через func, рекурсивны по умолчанию.

Условия

Для факториала необходимо написать условие выхода из рекурсии. Условный оператор реализован, как особая форма if. Она первым аргументом принимает условие, вторым список выражений(как в func).

(
    if (= n 0)
    (
        // true branch
        1
    )
    (
        // false branch
        2        
    )
)

Сам факториал

Теперь мы готовы написать функцию факториала. Она выглядит так:

(
    func factorial (n) ( // n - аргумент функции
        (
            if (= n 1)   // условие выхода
            (1)          // true branch
            (            // false branch
                (* (factorial (- n 1)) n) // аналог factorial(n - 1) * n на нашем языке
            )
        )
    )
)

Переменные

Теперь когда вы умеете писать функции, можете результат этой функции присвоить переменной. Переменные создаются с помощью особой формы let. Она первым аргументом принимает список из декларация. Декларация: (имя значение).

(let
(
    (x (factorial 5))
    (y 1)
    (s "hello world")
)
)

Как использовать let в func и if

Вы можете использовать let в функциях и условиях следующим образом:

// Гамма функция для натурального числа (Г(n+1) = n!)
(func gamma-for-n (n) (
    (
        let 
        ((x (- n 1))) // Первое выражение добавляет переменную x
    )
    (factorial x) // Второе возвращает результат функции
)
)

В if аналогично.

Базовые типы данных

Int

Целое число. С ним доступны операции:

  • (+ 1 2)
  • (- 1 2)
  • (* 1 2)
  • (/ 1 2) - с округлением вниз
  • (- 1) - унарный минус
  • (= 5 5)
  • (< 3 5) -> true
  • (> 3 5) -> false
  • (<= 3 5)
  • (>= 3 5)

Note

В этих операциях может участвовать только либо 2 int, либо 2 float. Вы можете преобразовывать float в int. Преобразование отсекает дробную часть: (int val)

float

Доступны все те же операции, что и для int.

Вы можете преобразовывать int в float. (float val).

Вы можете округлить float по правилам математики (round val).

bool

Логический тип данных. Записывается атомами:

  • true - истина;
  • false - ложь.

Во всех контекстах, где ожидается значение типа bool, небулевы значения неявно преобразуются по правилу:

  • nil преобразуется в false;
  • всё остальное преобразуется в true.

Язык предоставляет стандартный набор логических операций:

  • (not val) - возвращает значение обратное переданному
    (e.g., (not true) -> false, (not false) -> true);
  • (and a b c ...) - последовательно вычисляет выражения до первого ложного либо до конца списка, возвращая true, если все значения истины, либо false, если хотя бы одно из них ложно
    (e.g., (and true true) -> true, (and true false true) -> false);
  • (or a b c ...) - последовательно вычисляет выражения до первого истинного либо до конца списка, возвращая true, если хотя бы одно значение истино, либо false, если все они ложны
    (e.g., (or false true) -> true, (or false false false) -> false).

Поддерживает операцию проверки равенства:

  • (= true true) -> true;
  • (= false true) -> false;
  • (= false false) -> false.

Note

Во всех контекстах, где ожидается значение типа bool, небулевы значения неявно преобразуются по правилу:

  • nil преобразуется в false;
  • всё остальное преобразуется в true.

string

Строковой тип данных.

Доступна операция конкатенации: (+ "Hello, " "world!") -> "Hello, world!".

Поддерживает операции лексиграфического сравнения:

  • (= "hello", "hello") -> true;
  • (< "a", "b") -> true;
  • (> "a", "b") -> false;
  • (<= "a", "b") -> true;
  • (>= "a", "b") -> false.

Переменные

let

Вы можете создать переменную с помощью let. Как в любом функциональном языке, вы не можете модифицировать переменные.

(let
    (N 5)
    (x (+ N 1))
)

let принимает список из деклараций.

Декларация: список из имени переменной и значения.

Note

Вы можете в let ссылаться на другие переменные, объявленные в том же let. В примере x использует N.

Каждая переменная живет в своем лексическом окружении. Глобальном или окружении функции. Когда вы вызываете func или la для создания функции, все что лежит внутри функции лежит в своем окружении.

(let ((t 1))) //Какая-то константа
(func second (l) //Находит второй элемент списка
(
    (let
        (
            (t (tail l)) // Все кроме первого элемента списка
            (ans (head t))
        )
    )
    ans
)
)

Функции

Вы можете создать 2 типа функций. Анонимные (лямбда выражения) и именованные.

Именованные функции

Создать именованную функцию можно с помощью особой формы func. Синтаксис выглядит как

(func имя-функции (список из имен аргументов) (список из выражений)).

Список из выражений в функции интерпретируется до тех пор, пока какое-то выражение не вернет результат. Например let результат не возвращает. Это сделано для того, чтобы вы могли именовать переменные в функции. Пример:

(
   func double-list (l) // Умножает все элементы списка на 2
   (
       ( if l
           (
               (let
               (
                   (x (* 2 (head l)))
                   (new-head (list x))
                   (new-tail (tail l))
               )
               )
               (cat new-head (double-list new-tail))
           )
           nil
       )
   )
)

В примере вы так же можете видеть, что именованные функции по умолчанию поддерживают рекурсию

Лямбда выражения

Создаются с помощью особой формы la. Синтаксис выглядит как

(la (аргументы) (список из выражений))

Список из выражений интерпретируется так же, как и в func.

Important

Лямбда выражение не поддерживает рекурсию, даже, если вы дадите ему имя с помощью let

Функция как аргумент

Вы можете использовать функцию, как аргумент к другим функциям. Для определения таких функций удобно написать лямбда выражение. Пример использования типичной функции map для списков.

(
    func ListMap (f lst)
    (
        (if lst
        (
            (let
            (
                (x (f (head lst)))
                (new-head (list x))
                (new-tail (tail lst))
            )
            )
            (cat new-head (ListMap f new-tail))
        )
        (
            lst
        )
        )
    )
)
(ListMap (la (x) ((* x x))) (list 1 2 3)) // Квадрат от всех элементво списка
// [1, 4, 9]

Функция, как возвращаемое значение

Ваша функция может вернуть другую функцию. Пример:

(func make-adder (x)
(
    (
        la (y) (
        (+ x y)
        )
    )
)
)
(
    let
    ((add5 (make-adder 5))) //Функция, которая прибавляет 5
)
(add5 1) // 6

Tip

Предыдущий пример можно было написать и короче. Наш язык поддерживает каррирование. Получить функцию (make-adder 5) можно было записью (+ 5)

If

if

Специальная форма, выполняющая одно из двух выражений в зависимости от истинности условия.
Синтаксис: (if condition then-expr else-expr), где

  • condition - выражение, неявно приводящееся к bool;
  • then-expr - выражение, вычисляемое при истинности condition;
  • else-expr - выражение, вычисляемое при ложности condition.

Note

Вычисление ветвей ленивое: если condition истинно, то else-expr не вычисляется, и наоборот, если condition ложно, then-expr не вычисляется.

Списки

Список — упорядоченная последовательность элементов произвольного типа. Реализован как односвязный список. nil — пустой список, эквивалентен (list).

list

Создаёт список из переданных аргументов. Все аргументы вычисляются до создания списка.

(list expr1 expr2 ... exprN)

(list 1 2 3)        // List [1, 2, 3]
(list "a" "b" "c")  // List ["a", "b", "c"]
(list)              // nil

head

Возвращает первый элемент списка.

(head list)

(head (list 1 2 3))    // 1
(head (list "hello"))  // "hello"
(head nil)             // ошибка: head: empty list

tail

Возвращает список без первого элемента. Если список содержит один элемент — возвращает nil.

(tail list)

(tail (list 1 2 3))  // List [2, 3]
(tail (list 1))      // nil
(tail nil)           // ошибка: tail: empty list

cat

Конкатенирует два списка. nil трактуется как пустой список.

(cat list1 list2)

(cat (list 1 2) (list 3 4))  // List [1, 2, 3, 4]
(cat nil (list 1 2))         // List [1, 2]
(cat (list 1 2) nil)         // List [1, 2]
(cat nil nil)                // nil
(cat 1 (list 2 3))           // ошибка: cat: expected 2 lists

Проверка типа

is-type с аргументом list возвращает true для любого списка, включая nil.

(is-type list (list 1 2))  // true
(is-type list nil)         // true
(is-type list 42)          // false

Итерация

Списки не имеют встроенного цикла — обход выполняется через рекурсию. Паттерн: проверить список на пустоту через if, обработать head, рекурсивно обработать tail.

Сумма элементов:

(
    func sum (lst)
    (
        (if lst
            ((+ (head lst) (sum (tail lst))))
            0
        )
    )
)

(sum (list 1 2 3 4 5))  // 15

Фильтрация:

(
    func filter-positive (lst)
    (
        (if lst
        (
            (let
            (
                (h (head lst))
                (rest (filter-positive (tail lst)))
            )
            )
            (if (> h 0)
                (cat (list h) rest)
                rest
            )
        )
        nil
        )
    )
)

(filter-positive (list -1 2 -3 4 5))  // List [2, 4, 5]

Проверка типов

Cheremsha предоставляет встроенную функцию для проверки типа значения в runtime.

is-type

Возвращает true если значение expr имеет тип type, иначе false.

(is-type type expr)

type — символ названия типа. expr — вычисляемое выражение.

Поддерживаемые типы

СимволТип
intцелое число
floatчисло с плавающей точкой
booleanбулево значение
strстрока
listсписок (включая nil)
funcфункция (замыкание)
 
(is-type int 42)             // true
(is-type int 3.14)           // false
(is-type float 3.14)         // true
(is-type boolean true)       // true
(is-type str "hello")        // true
(is-type list nil)           // true
(is-type list (list 1 2 3))  // true
(is-type func (la (x) (x)))  // true

Каррирование

is-type поддерживает каррирование — можно создать функцию-предикат для конкретного типа:

(let ((is-int (is-type int))))

(is-int 42)    // true
(is-int 3.14)  // false

Замечания

  • Проверка типа выполняется в runtime, а не на этапе компиляции
  • nil считается списком: (is-type list nil) возвращает true
  • Для функций, созданных через func, тип тоже func

Инфиксные выражения

Cheremsha поддерживает вычисление арифметических выражений в привычной инфиксной нотации через eval-expr.

eval-expr

Вычисляет арифметическое выражение в инфиксной нотации, переданное как строка.

(eval-expr expr-string)

expr-string — строка с арифметическим выражением. Возвращает int или float.

Поддерживаемые операции

ОператорОписаниеПриоритет
+сложениенизкий
-вычитание / унарный минуснизкий
*умножениевысокий
/делениевысокий
()группировка—

Стандартный приоритет операций: * и / вычисляются раньше + и -.

(eval-expr "1+2+3")      // 6
(eval-expr "2*3+4")      // 10
(eval-expr "2*(3+4)")    // 14
(eval-expr "-5+3")       // -2
(eval-expr "10/2")       // 5
(eval-expr "1.5+2.5")    // 4.0

Переменные

Если в выражении встречается идентификатор (буква или _, затем буквы, цифры, _), его значение ищется в текущем окружении.

(let ((a 3)))
(let ((b 4)))
(eval-expr "a*a + b*b")  // 25

Замечания

  • Типы не смешиваются: "1+1.5" вызывает ошибку
  • Пробелы игнорируются: "1 + 2" и "1+2" эквивалентны
  • Имена переменных не могут содержать -: a-b распознаётся как a, -, b

Мапа

map

Ассоциативная коллекция, хранящая пары “ключ-значение”. Ключами могут являться только int, float и string. Все ключи в одном map могут иметь только один тип. Одному ключу может принадлежать только одно значение.

Операции с map:

  • (map (("apples" 2) ("bananas" 2) ("oranges" 8))) - создание map из переданного списка пар;

Note

Если в списке пар окажется несколько пар с одинаковым ключом, сохраняется значение из самой правой такой пары.

  • (map-get m key) - получение значения, связанного с ключом key из m;

Note

Если переданный ключ отсутствует в map, возвращает значение nil.

  • (map-insert m key value) - возвращает новый map, в котором key связан со значением value;
  • (map-delete m key) - возвращает новый map, в котором нет пары с ключом key.

Note

Если переданный ключ отсутствует в map, ошибка не возникает - возвращает копию переданного map.

Note

nil нельзя хранить в map в качестве значения.

Библиотечные функции для List

В данном разделе описаны основные инструменты для работы со списками. Функции fst и snd являются глобальными, в то время как остальные сгруппированы в модуле List.

Глобальные функции

fst

Возвращает первый элемент списка. Является алиасом для встроенной функции head.

(fst list)

(fst (list 1 2 3)) // 1
(fst nil)          // ошибка: head: empty list

snd

Возвращает второй элемент списка. Эквивалентно получению головы от хвоста списка.

(snd list)

(snd (list "первый" "второй" "третий")) // "второй"
(snd (list 1))                         // ошибка: tail: empty list

Модуль List

Для использования функций этого модуля необходимо использовать префикс List.

Map

Применяет функцию f к каждому элементу списка lst и возвращает новый список результатов[cite: 2].

(List.Map f lst)

(func square (x) ((* x x)))
(List.Map square (list 1 2 3)) // List [1, 4, 9]

Filter

Создает новый список, содержащий только те элементы lst, для которых предикат pred вернул true. Если предикат возвращает nil или false, элемент отбрасывается.

(List.Filter pred lst)

(List.Filter (la (x) ((> x 0))) (list -1 5 -2 8)) // List [5, 8]

Fold

Сворачивает список lst, последовательно применяя функцию f к аккумулятору acc и очередному элементу.

(List.Fold f acc lst)

// Сумма элементов:
(List.Fold + 0 (list 1 2 3)) // 6

Nth

Возвращает элемент по указанному индексу n (индексация начинается с 0). Если индекс выходит за пределы списка, возвращает nil.

(List.Nth n lst)

(List.Nth 1 (list "a" "b" "c")) // "b"
(List.Nth 5 (list 1 2))         // nil

Length

Вычисляет количество элементов в списке. Работает рекурсивно.

(List.Length lst)

(List.Length (list 1 2 3 4)) // 4
(List.Length nil)            // 0

Rev

Переворачивает список, меняя порядок элементов на обратный. Использует Fold для построения нового списка. Сложность операции — $O(n)$.

(List.Rev lst)

(List.Rev (list 1 2 3)) // List [3, 2, 1]

Fold2

Аналог Fold, но обрабатывает два списка одновременно. Итерация прекращается, как только один из списков заканчивается.

(List.Fold2 f acc l1 l2)

// Создание списка пар:
(List.Fold2 (la (acc x y) ((cat acc (list (list x y))))) nil (list 1 2) (list 3 4))
// List [[1, 3], [2, 4]]

Push

Добавляет элемент x в начало списка lst. Фактически является оберткой над cat и list.

(List.Push x lst)

(List.Push 10 (list 1 2)) // List [10, 1, 2]

Pop

Возвращает список без первого элемента. Эквивалентно встроенной функции tail.

(List.Pop lst)

(List.Pop (list 1 2 3)) // List [2, 3]

Разделение на файлы

Cheremsha поддерживает разбиение программы на несколько файлов с помощью include.

include

Выполняет код из файла filename и загружает все определённые в нём имена в текущее окружение.

(include "filename")

filename — строковый литерал с путём к файлу. Путь указывается относительно рабочей директории интерпретатора.

Выражения в файле выполняются последовательно в том же окружении, в котором вызван include. Имена, определённые через func и let в файле, становятся доступны после возврата из include.

Note

Многострочный код поддерживается только в файлах. В REPL каждая строка обрабатывается отдельно — используй include для загрузки многострочных определений.

Файл math.x:

(func square (x) ((* x x)))
(func cube (x) ((* x (* x x))))

Основной файл:

(include "math.x")

(square 4)  // 16
(cube 3)    // 27

Вложенный include — файл может подключать другие файлы:

// geometry.x
(include "math.x")

(func circle-area (r) ((* 3.14159 (square r))))

(include "geometry.x")

(circle-area 5)  // 78.53975

Модули

Модуль группирует связанные функции и переменные под общим именем, предотвращая конфликты имён.

module

Выполняет тело модуля в изолированном окружении и добавляет все определённые имена с префиксом Name. в текущее окружение.

(module Name (
    expr1
    expr2
    ...
))

Name — идентификатор модуля. Тело — последовательность выражений, обычно func и let.

После выполнения (module Math (...)) имена, определённые внутри, становятся доступны как Math.foo, Math.bar. Неквалифицированные имена снаружи модуля недоступны.

Note

Многострочный синтаксис модуля поддерживается только в файлах. В REPL вся конструкция должна быть на одной строке: (module Name ((func foo (x) (x)))).

(module Math (
    (func square (x) ((* x x)))
    (func cube (x) ((* x (* x x))))
    (let ((pi 3.14159)))
))

(Math.square 5)  // 25
(Math.cube 3)    // 27
Math.pi          // 3.14159

(square 5)       // ошибка: Symbol square not found

Несколько блоков одного модуля

Один модуль можно определять в нескольких блоках — имена из всех блоков добавляются в общее пространство имён.

(module Strings (
    (func to-upper (s) (...))
))

(module Strings (
    (func to-lower (s) (...))
))

(Strings.to-upper "hello")  // работает
(Strings.to-lower "HELLO")  // работает

Рекурсия

Функции внутри модуля вызывают себя по неквалифицированному имени:

(module Math (
    (func fact (n) (
        (if (= n 0)
            1
            ((* n (fact (- n 1))))
        )
    ))
))

(Math.fact 5)  // 120

Замечания

Модули не создают отдельного пространства имён в памяти — это соглашение по именованию, применяемое автоматически интерпретатором. Функции внутри модуля видят друг друга по неквалифицированным именам, но снаружи доступны только через Name..

Ввод-вывод (IO)

Все функции и константы для работы с вводом-выводом имеют префикс io.. В языке определены два базовых типа потоков: input (чтение) и output (запись). Потоком может быть как файл, так и стандартные потоки ввода-вывода.

Стандартные потоки

Для удобства работы с терминалом предусмотрены встроенные алиасы:

  • io.stdin: Стандартный поток ввода (тип input).
  • io.stdout: Стандартный поток вывода (тип output).

io.open-read

Открывает файл для чтения. Возвращает объект типа input.

(io.open-read filename)

(let ((file (io.open-read "data.txt"))))
(io.readline file) // считает строку

io.open-write

Открывает файл для записи. Возвращает объект типа output.

(io.open-write filename)

(let ((file (io.open-write "log.txt"))))
(io.write file "Hello, world!") // запишет Hello world

io.read

Читает из потока input указанное количество символов. Возвращает список, состоящий из двух элементов: прочитанной строки и нового экземпляра потока.

(io.read input char_count)

(let ((res (io.read io.stdin 5))))
(head res) // Возвращает строку из 5 символов

io.readline

Читает одну строку из потока input. Аналогично read, возвращает список из (string, input).

(io.readline input)

(
    func read-and-print ()
    (
        (let ((input-data (io.readline io.stdin))))
        (io.write io.stdout (head input-data))
        
    )
)

io.write

Записывает строку в поток output. Возвращает обновленный экземпляр потока output.

(io.write output string)

(io.write io.stdout "Ready.") // Выводит "Ready." в терминал
(io.write (io.open-write "test.txt") "Data") // Записывает в файл

Проверка типа

Для проверки потоков в функции is-type используются соответствующие символы.

(is-type input-stream io.stdin)   // true
(is-type output-stream io.stdout) // true

Пример: Чтение файла целиком

Поскольку итерация в языке реализуется через рекурсию, чтение данных до конца потока (через проверку возвращаемого значения на пустую строку) выглядит так:

(
    func print-file (file)
    (
        (let ((res (io.readline file))))
        (let ((line (head res))))
        (if (not (= line ""))
            (
                (let ((_ (io.write io.stdout line))))
                (print-file (head (tail res))) // Передаем обновленный поток
            )
            nil
        )
    )
)

Утилиты

Здесь описаны функции, которые облегчат вашу работу с функциями.

pipe

Позволяет делать композицию нескольких функций. Первым аргументом принимает список из функций.Принимает вторым аргументом аргумент, который подастся первую функцию. Аргумент сначала подается в первую функцию, потом результат первой во вторую и.т.д. func (arg funcs) pipe

(pipe (list (+ 5) (- 6)) 1) // вернет 0

pipe-monadic

Позволяет производить монадические вычисления. Принимает первым аргументом bind, вторым список функций, который принимают немонадический тип, а возвращают монадический, третьим аргумент. func pipe-monadic (bind funcs arg) Примеры смотрите в Монады

Монады

В языке Cheremsha вы можете писать монады.

Пример монады Result

Important

Рекомендуется ознакомиться с главой Утилиты перед прочтением примера.

Пример с монадой Result из F#. Если в пайплайн попала ошибка, то она вернется в конце пайплайна.

(
    func result (x) (
        (map (("Result" x)))
    )
)
(
    func error (x)(
        (map (("Error" x)))
    )
)
(
    func result-bind (f x)
    (
        (
            if (map-get x "Error")
            (
                (error x)
            )
            (
                (f (map-get x "Result"))
            )
        ) 
    )
)
(func div (x y)
(
    (
        if (= y 0)
        (
            (error "Division by 0")
        )
        (
            (result (/ x y))
        )
    )
)
)
(
    func adder (x)(
        (la (y) (( pipe (list (+ x) result) y)) )
    )
)
(pipe-monadic result-bind (list (la (x) ((div 5 x))) (adder 5) ) (result 0))
(pipe-monadic result-bind  (list (la (x) ((div 5 x))) (adder 5) ) (result 2))
